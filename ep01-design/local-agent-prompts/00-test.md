Start the design system for "Bench Board", a dark web app that shows local AI model benchmarks.

1. Create these paint styles (name = colour): bg #0f1115, surface #181b22, line #2a2f3a, text #e8eaf0, muted #8a93a6, accent #f5b942, good #4ade80.
2. Create text styles: H1 (Inter Bold 56, line height 64), Body (Inter Regular 16, line height 24), Body bold (Inter Semi Bold 16, line height 24).
3. Make a Button component: an auto-layout frame (horizontal, padding 14 24, corner radius 12, hug contents) filled with the accent style, holding the text "See the leaderboard" in Body bold with the bg style.
4. Turn it into a variant set with Type=Primary, and add variants Type=Secondary (surface fill, 1 px line stroke, text style text) and Type=Disabled (opacity 0.4).
Check the result with get_node before you finish.
