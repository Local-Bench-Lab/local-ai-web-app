Task 11 of 11 for "Bench Board": the real logo is ready at /config/designs/bench-board-logo.png (made in PhotoCraft). Use list_layers to find the "Logo" component. Remove its fills, strokes and dashes (set_properties fills [], strokes [], dashes []), then place the image inside it with run_command image.place {path, parent: <Logo id>, x 0, y 0, width 40, height 40, mode "fill"}. Name the image layer "logo image" and set its constraints to scale both ways, so every Logo instance (nav, hero, mobile) shows the new logo.
