# Ep 4: Local AI builds the frontend

Video: https://youtu.be/ygrqkF7pN4g

`runs/` has every session from the episode, in order. Each step is `opencode run --agent <agent> "<prompt>"`:

1. `scaffold.sh`: the starter app by hand (Vite, React, TypeScript, Vitest, the three checks).
2. `components.sh`: the plan, then Button, Card, Field, Nav, Drawer.
3. `racebar.sh`: the RaceBar component.
4. `review.sh`: the review loop (visual checker, React and CSS reviewers, the judge, fix rounds).
5. `pages.sh`: Home, Leaderboard, Request.
6. `home.sh`: the second try, with a tighter prompt.

Also here:
- `app-design-brief.md`: what the pages should look like and do, which the agents read.
